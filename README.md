# Аталык — посадочная страница записи на экскурсию

Статический mobile-first лендинг для короткого маршрута родителя: выбрать класс → проверить наличие → понять следующий шаг → записаться на экскурсию.

Демо: https://ya-yura.github.io/atalyk-tour-landing-20260811/
Репозиторий: https://github.com/ya-yura/atalyk-tour-landing-20260811

## Локальный запуск

Проект не требует зависимостей. Из папки проекта запустите любой статический сервер, например:

```powershell
py -m http.server 4173
```

Затем откройте `http://localhost:4173/`. Прямое открытие `index.html` не подходит: браузеру нужен HTTP для загрузки `content/availability.json`.
Для локальной проверки dev-пометки подключения endpoint используйте `http://localhost:4173/?mode=demo`; без query-параметра внутреннее сообщение скрыто.

## Что менять перед публикацией

- `content/availability.json` — единственный источник статусов классов. Обновите `checkedAt`, значения `status`/`places`, `needsConfirmation` и `note` после письменной сверки со школой.
- `index.html` — тексты и SEO-поля. `canonical` и `og:url` настроены на опубликованное демо; при переносе на другой домен обновите их.
- `app.js` — задайте `FORM_ENDPOINT` только после передачи школой реального endpoint или согласованного канала. Пока значение пустое, форма не имитирует успешную отправку и сообщает о demo-режиме.
- `styles.css` — визуальные токены в `:root`.

UTM-поля `utm_source` и `utm_campaign` сохраняются в форме. События для будущей аналитики отправляются как `CustomEvent` на `window`: `class_selected`, `availability_viewed`, `tour_form_started`, `tour_form_submitted`, `tour_form_error`. Подключите обработчик через `window.__ATALYK_ANALYTICS__` после согласования аналитики и идентификаторов.

## Источники и границы данных

Подтверждённые исходные данные проверены 11.08.2026 по [официальному сайту](https://atalyk.ru/), [контактам школы](https://atalyk.ru/contacts) и [карточке 2ГИС](https://2gis.ru/krasnodar/search/%D0%90%D1%82%D0%B0%D0%BB%D1%8B%D0%BA). В интерфейсе не используются неподтверждённые рейтинг, отзывы, лицензии, результаты экзаменов или обещания зачисления. Адрес, телефон, официальный логотип и четыре фотографии взяты с официальных материалов; перед рекламным использованием фотографий стоит подтвердить права у школы.

## Сборка и GitHub Pages

Сборка как отдельный шаг не нужна: это готовый набор статических файлов. Для Pages используйте GitHub Actions из `.github/workflows/pages.yml`. В workflow подставляется содержимое репозитория без сторонних зависимостей.

## Вопросы школе перед production

1. Актуальны ли места по каждому классу на момент публикации?
2. Что означает верхняя формулировка «дополнительный набор с 1 по 9 классы», если 9-й класс отмечен как закрытый?
3. Актуальны ли пробная первая неделя за 7 500 ₽ и специальные условия?
4. Какие даты и время экскурсий доступны?
5. Куда направлять заявки и кто отвечает за подтверждение времени?
6. Есть ли разрешение на использование фотографий и какие точные юридические/контактные данные можно добавить в SEO-разметку?
